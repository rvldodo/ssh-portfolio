How to connect

Three steps, about ten seconds

SSH is the tool developers use to log in to servers. It comes built into macOS, Linux, and Windows 10+, so there's nothing to install.

01

Open a terminal

  • macOS ⌘ Space, type “Terminal”
  • Windows Start menu → “PowerShell” or “Terminal”
  • Linux Ctrl Alt T
02

Run the command

Paste it and press Enter. No password and no account.

$ {{.Command}}

03

Say yes, once

On your first visit, SSH asks whether to trust the server. Type yes. It won't ask again.

FAQ

Questions

Is this safe to run?
Yes. This server doesn't give you a shell or access to any machine. It only runs this portfolio app, and nothing is installed on your computer. You can't type commands on the server, only navigate the pages. Press q to leave.
It says “Connection refused” or just hangs
Some office, school, and public Wi-Fi networks block SSH (port 22). Try another network, such as your phone's hotspot. Everything is also in the preview above.
It asks me for a password
Just press Enter. No password is needed. If it keeps asking, check that you typed exactly {{.Command}}.
I see “REMOTE HOST IDENTIFICATION HAS CHANGED”
Your computer remembers an older key for this address. {{if .Fingerprint}}If the fingerprint it shows matches {{.Fingerprint}}, {{end}}remove the old entry with ssh-keygen -R {{.Address}} and connect again.
Why SSH instead of a normal website?
I build backend systems and run servers for a living, so a portfolio served from a server I wrote in Go felt fitting. It uses Charm's Wish and Bubble Tea, with content shared with this page.
